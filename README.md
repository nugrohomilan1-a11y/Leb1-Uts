# Website Toko Buku Online

## Deskripsi
Website Toko Buku Online merupakan proyek Ujian Tengah Semester (UTS) mata kuliah Pemrograman Web 1. Website ini dibuat untuk memudahkan pengguna dalam melihat katalog buku, melakukan pemesanan, dan memeriksa status pengiriman buku.

## Fitur Website
1. **Login**  
   Pengguna dapat masuk menggunakan email dan password yang telah tersedia.

2. **Dashboard**  
   Menampilkan halaman utama dan menu navigasi website.

3. **Katalog Buku**  
   Menampilkan daftar buku beserta kode barang, nama buku, jenis, edisi, stok, dan harga. Pengguna juga dapat menambahkan buku baru.

4. **Checkout**  
   Pengguna dapat memilih buku, menentukan jumlah pembelian, mengisi data pemesan, dan melihat total harga.

5. **Tracking Pengiriman**  
   Pengguna dapat memeriksa status pengiriman menggunakan nomor Delivery Order (DO).

## Teknologi yang Digunakan
- HTML: Membuat struktur halaman website.
- CSS: Mengatur tampilan dan desain website.
- JavaScript: Mengatur fungsi dan interaksi website.
- DOM dan Event: Mengelola perubahan elemen halaman berdasarkan tindakan pengguna.

## Cara Menjalankan Website

1. Download atau clone repository ini.
2. Buka folder project menggunakan Visual Studio Code.
3. Pastikan seluruh file HTML, CSS, dan JavaScript berada di folder yang sesuai.
4. Pastikan gambar cover buku tersedia di folder `img`.
5. Buka file `login.html` menggunakan browser.
6. Masukkan email dan password yang tersedia pada file `data.js`.
